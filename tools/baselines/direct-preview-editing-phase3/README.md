# Direct preview editing Phase 3 evidence

Phase 3 adds direct, local-draft editing for existing action-card ability
paragraphs. Primary, split-defence, timing and Bonus paragraphs resolve to
their original stored paths; empty or structural regions continue to open the
complete centre editor.

`interaction-evidence.json` records the exercised ability identity,
rich-text, lifecycle, responsive and export-safety checks. The Phase 0 export
fixture was regenerated against Phase 3 and passed geometry-only verification.
Strict verification reported decoded-pixel variance in the trim and bleed hero
character card plus the checked-out Phase 0 interaction JSON's line-ending byte
count. Phase 3 changes no renderer or export module.
