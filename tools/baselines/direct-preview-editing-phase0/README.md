# Direct preview editing Phase 0 evidence

This baseline is generated by the real action-card exporter at
`/tools/direct-preview-baseline/run.html`. It builds a deterministic set in
memory and never reads or writes the workshop store.

The fixture covers an ordinary hero, a split hero, villain and minion cards,
formatted ability text with only Bonus ability 2 populated, a custom boost
symbol, and a whole-face replacement. The trim and bleed ZIPs are written to
`exports/direct-preview-phase0/`; their entries are fingerprinted in the
committed evidence manifest.

The `screenshots/` folder records both the comfortable desktop prototype and
the phone-sized centre-editor fallback. `interaction-evidence.json` records
the measured overlay alignment and the exercised pointer, keyboard, focus,
and responsive behaviours.

Regenerate the output on the dedicated development origin, copy fresh UI
screenshots into `screenshots/`, then capture or verify the manifest with:

```powershell
node tools/mobile-baseline/evidence.mjs capture --manifest tools/baselines/direct-preview-editing-phase0/evidence-manifest.json --root exports/direct-preview-phase0/fixture.awset.json --root exports/direct-preview-phase0/cards-trim.zip --root exports/direct-preview-phase0/cards-bleed.zip --root exports/direct-preview-phase0/run.json --root tools/baselines/direct-preview-editing-phase0/screenshots --root tools/baselines/direct-preview-editing-phase0/interaction-evidence.json
node tools/mobile-baseline/evidence.mjs verify --manifest tools/baselines/direct-preview-editing-phase0/evidence-manifest.json
```

Raw ZIP hashes are informational because archive timestamps vary. Each stored
PNG entry is compared separately by dimensions and decoded pixel samples.
